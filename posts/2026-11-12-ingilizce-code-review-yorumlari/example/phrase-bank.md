# Code review phrase bank

## Asking
- Can you help me understand why ...?
- What happens if ... is null / empty / very large?
- Is this called from anywhere else?
- Am I missing something here?

## Suggesting
- Have you considered ...?
- What do you think about ...?
- Would it make sense to ...?
- One option could be ...
- I'd suggest ... because ...
- It might be worth extracting this into ...

## Pointing out a problem
- I think this will ... when ...
- This looks like it could ... Should we ...?
- I'm worried that ... because ...

## Weight
- nit: / Optional: / Not blocking, but ...
- This one is blocking for me because ...
- Feel free to ignore.

## Approving
- Looks good to me. (LGTM)
- Approving with a couple of nits.
- Nice work, especially ...

## Replying as the author
- Good catch, fixed in <commit>.
- Done. / Updated.
- I see your point, but I'd keep it because ... What do you think?
- Let's handle that in a follow-up PR. I opened #<issue>.
